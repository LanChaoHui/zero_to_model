# 一个人的成长记录

**1996 — 现在**

> 我今年 30 岁，初中学历，在一家外包公司写 CRUD。
> 2026 年 9 月，我开始从初中数学学起。
> 这个仓库用来记这件事，以及它之前的所有事。

写在最前面：

1. 这里写下的东西我不删。写错了就改，但会留下改的痕迹。
2. 记不清的地方我写"记不清"，不编细节。
3. 我不写形容词。"今天收获很大"这种话，我分不清是真话还是自我安慰。日期、题号、数字能分清。

---

## 一、1996—2011｜一个很普通的开头

1996 年出生。家里普通，父母是那种"好好读书"的人。

初中那几年，我把时间花在了一个游戏上。那几年具体怎么过的，我记不太清了——记忆里只剩下开机、上线、下线、天亮。

结果是：初中读完了，没有升学。

这不是一个戏剧性的决定。没有人跟我说"你别读了"，也没有一场激烈的争吵。就是某一天，上学这件事自然停了。

十八岁不到，我成了一个没有学历、也没有技能的人。

## 二、2011—2014｜鞋厂

第一份工作在鞋厂。

流水线的活儿不需要想事情。手在动，脑子是空的。一天里唯一需要判断的事，是几点下班。

那几年我学会了一件不太好的事：**把日子过成等待**。等下班，等发工资，等休息日。等到最后，一年过去了，我说不出这一年发生过什么。

钱是有的，但很少。人是活的，但没什么变化。

## 三、2015｜网吧里的一个广告

休息日我去网吧。

某一次点开了一个培训机构的广告，页面上写着"留下电话，老师给你规划"。我填了。第二天真的有电话打过来。

我跟父母说了。他们不懂 IT 是什么，只知道儿子不想在鞋厂待着了。那笔学费是他们的钱。

后来我常想：**那是我这辈子唯一一次，有人替我下注。**

## 四、2015—2018｜北大青鸟，然后入行

在北大青鸟学了几年。学的东西现在回头看很浅：HTML、Java 基础、CRUD、一个能跑起来的项目。

但那时候够了。行业缺人，不卡学历，会写增删改查就能上班。

我进了一家小公司。第一次拿到工资那天，我觉得自己终于从"没有"变成了"有一点"。

那几年是我人生里唯一一段"越走越顺"的时间。顺到让我以为，后面也会一直这样。

## 五、2018—2025｜十年 CRUD

换过几次工作。工资涨过。

技术上没有本质变化：接需求、写接口、改页面、上线、修 bug。做熟以后，一天的工作两三个小时能做完，剩下的时间用来等下班。

我不是没想过改变。前几年也买过书、也刷过题、也想过进大厂。但那些努力有个共同点：**它们都不改变我的位置**。看完一本书，我还是那个写 CRUD 的人；刷完一套题，简历第一关还是学历。

后来我就不太想了。

这可能是我这十年里最危险的一件事——不是失败，是**不再觉得失败是个问题**。

## 六、2026｜剑落下来之前

今年公司里的话术变了。

领导说"这个用 AI 开发很快"，产品说"这个让 AI 生成一下"。他们不是在夸工具，他们是在重新给我的工作定价。

我坐在工位上，旁边是 01 年、02 年的同事。他们叫我哥，写代码比我快，学历比我好，还有十年可以试错。

我不怕被年轻人超过。我怕的是另一件事：**我连被比较的资格都在消失。**

那把剑悬了很多年。今年我第一次听见它响。

## 七、2026 年 9 月 4 日｜决定

那天我把会的东西和不会的东西列了一张表。

**会**：CRUD、业务理解、把一个需求从文档做到上线、在一堆烂摊子里活下来。

**不会**：数学、算法、模型内部到底在算什么。

然后我算了一笔很简单的账：我所有的能力，都建立在"有人需要人来写 CRUD"这个前提上。而这个前提正在消失。

那天我定了路线：

```
数学（从初中开始） → 算法 → AI 工程 → 自己实现一个小模型
```

为什么不直接学 AI：我打开过机器学习的书，第一页就是求和符号和矩阵。我看得懂每个字，连起来不知道在说什么。

为什么不报班：我见过太多"AI 应用开发"课，教的是调 API、拼提示词。这些我一周就能学会，学会之后也只是从"写 CRUD 的人"变成"写 CRUD 加调 API 的人"。**位置没变。**

为什么不考研：学历断在初中，专升本到硕士要四到六年，终点是一个 35 岁的应届生。用最贵的时间去补一张最没用的纸。

一路往回退，退到初一的有理数运算。退到那儿我才承认：我不是数学不好，我是**没有**数学。

"不好"是一种可以维持的状态，"没有"是一个可以从头建的东西。

## 八、2026 年 10 月｜开始，以及推倒重来

九月开始学，学到十月，我把课程推倒重来了一次。

原因写在 [2026 年记录](log/2026.md) 里：第一个月里，我有一半时间在改规则、重排目录、修记录格式，真正做题的时间不多。台账做得很漂亮，章却没往下走。

十月十二日，从头开始计数。到今天：

```
教材：人教版，初中三年，一共 33 章
已完成：1 章（第一章 有理数）
已作答：74 题
错题：11 条，全部记着，一条没删
用时：7 周
```

七周，一章。按这个速度，三十三章要四年。

这个数字我算过很多次，每次都想停。

但我又算了另一笔：如果不停，2029 年我 33 岁，有一块完整的地基；如果停，2029 年我 33 岁，还在改 if-else，并且知道自己曾经想过要改。

第二笔更贵。

## 九、现在｜每天 1—2 小时

日子大概是这样：

- 22 点以后开始。白天上班，晚上学。
- 23:00 提醒自己还剩半小时，23:20 做最后一题，23:30 硬停。
- 学的顺序全部交给教材，我不自己排。今天学哪一节，书上写着。
- 每道题有编号（`NM-CH01-20261018-03` 这种），每次作答记过程：独立做完的，还是要提示、要停很久才做出来的。
- 错了记主因。不写"粗心"——粗心是症状，不是原因。
- 有整天空白的时候。空着就空着，不补写。

我用 AI 辅助学习（WorkBuddy + DeepSeek）。它讲、它出题、它记账；我自己算、自己核、自己判断它讲得对不对。

到现在，我在它给的材料里抓到 5 处错误。抓错不是为了证明它不行，是因为**我得保持能抓错的能力**。不然就不是我在学，是它在喂。

## 十、以后｜我先给自己定好什么叫失败

免得以后含糊：

- 连续 3 个月没有任何作答记录 → 失败。不许说"最近忙"。
- 到 2029 年还停在初中阶段 → 失败。不许说"进度慢"。
- 只写总结、不写题号和错因 → 失败。这是最隐蔽的一种，看起来最努力。

如果真失败了，这个仓库也不删。它会留在这儿，作为一份诚实的记录：一个人试过，没成。

我不确定这条路能不能走通。

我能确定的是，这里写下的每个数字都是真的，包括那些难看的。
